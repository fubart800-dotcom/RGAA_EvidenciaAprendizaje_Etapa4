Área del círculo

Este ejercicio utiliza una función que recibe el radio de un círculo y devuelve su área. La fórmula utilizada es: Área = π × radio × radio.

Funcionamiento:

1. Se solicita el valor del radio.

2. Se llama a la función calcularAreaCirculo().

3. Se calcula el área utilizando Math.PI.

4. Se utilizan dos decimales con toFixed(2).

5. La función devuelve el resultado con return.

Índice de Masa Corporal (IMC)

Este ejercicio calcula el Índice de Masa Corporal utilizando el peso y la estatura de una persona. La fórmula es: IMC = peso / altura².

Funcionamiento:

1. Se solicita el peso en kilogramos.

2. Se solicita la altura en metros.

3. Se llama a la función calcularIMC().

4. Se utiliza Math.pow() para elevar la altura al cuadrado.

5. Se utiliza Math.round() para redondear el resultado.

6. Se utilizan condiciones if, else if y else.

7. Se muestra el resultado y su clasificación.
